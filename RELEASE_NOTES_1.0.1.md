# CiArpeSDS 1.0.1

**English** · Free **14-day trial** from the first start with every feature, then a **29 € one-time licence**
via PayPal (activation code by email, works offline, ACTIVATE button next to INFO).
Control your **Uniden SDS200** from a Windows 10/11 PC over the home network: network audio with voice filters,
the scanner's RF waterfall, FROM–TO search with modulation, Close Call and Discovery with STOP / RESUME / NEXT,
search hits added to your favorites list in one click, spreadsheet-style list editor with USB read/write and
automatic backup, recordings and statistics, phone listening page. English and Italian interface.
What's new in 1.0.1: every new 1.0 control translated to English, README_EN.txt in the package.
